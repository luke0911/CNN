## 🚀 빠른 시작 (체크포인트에서 재개)

### 방법 1: VSCode에서 F5로 실행 (권장) ⭐

1. VSCode에서 `object_detection` 폴더 열기
2. `학습_시작_yolov8s.py` 파일 열기
3. **F5** 누르기
4. 드롭다운에서 **"🚀 YOLOv8s Full 학습 시작"** 선택
5. 체크포인트 감지 메시지에서 **[1]** 입력 (재개)
6. **'y'** 입력하여 시작!

### 방법 2: 터미널에서 실행

```bash
cd object_detection
python3 학습_시작_yolov8s.py
```

```

## 💡 학습 재개의 장점

### ✅ 체크포인트 재개를 사용하면:
- 🎯 **정확한 지점**에서 재개 (4 epoch 이후)
- 💾 **이전 학습 데이터** 유지 (optimizer 상태, learning rate 등)
- ⏱️ **시간 절약** (이미 완료된 4 epoch를 다시 할 필요 없음)
- 📈 **연속적인 학습 곡선** 유지

### ❌ 처음부터 시작하면:
- ⏰ 추가 시간 소요 (약 40분 더 필요)
- 📊 이전 학습 데이터 손실
- 🔄 같은 작업 반복

**→ 대부분의 경우 [1] 체크포인트 재개를 선택하는 것이 좋습니다!**

## 🔍 학습 진행 상황 확인

학습 중에는 터미널에서 실시간으로 확인 가능:

```
Epoch   GPU_mem   box_loss   cls_loss   dfl_loss   Instances   Size
5/100   7.4G      1.234      2.345      1.123      45          640
```

### 주요 지표 의미:
- **box_loss**: 박스 위치 정확도 (낮을수록 좋음)
- **cls_loss**: 클래스 분류 정확도 (낮을수록 좋음)
- **dfl_loss**: Distribution Focal Loss (낮을수록 좋음)

## 📁 체크포인트 파일 위치

```
object_detection/
└── runs/
    └── train/
        └── stairs_yolov8s_full/
            ├── weights/
            │   ├── best.pt      ⭐ 현재까지 최고 성능 모델
            │   └── last.pt      🔄 마지막 체크포인트 (재개용)

- **last.pt**: 가장 최근 epoch의 체크포인트 (재개할 때 사용)
- **best.pt**: 검증 성능이 가장 좋았던 모델
